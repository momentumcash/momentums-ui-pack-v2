# Momentum's UI Pack v2

A Claude Code skill that makes Roblox UI look like a front-page game: shops, HUDs, inventories, egg hatch, daily rewards, settings, 3D tilting menus, button juice. One command, one rulebook, checked before it's shown.

## Install
Copy the `momentum-ui-pack` folder into `~/.claude/skills/` (Windows: `C:\Users\<you>\.claude\skills\`). Restart Claude Code.

Optional add-ons (free, from their creators):
- **Cryptic's GUI** (art-kit path for shops/hatch screens): download from Crypticplay_RBLX's official release, github.com/Crypticplayz/cryptics-gui
- **Kitkopika's UI skills** (deep-dives on style, juice, 3D): `npx skills add Kitkopika/roblox-ui-skills`
- **Roblox Studio MCP** so Claude can build straight into your game.

Headless builder needs Python 3 + Pillow (`pip install pillow`).

## Use
`/momentum-ui-pack` or just ask: *"make a shop UI for my pet sim"*, *"my HUD looks cheap, fix it"*, *"make my settings menu a 3D tilting panel"*.

Includes free UI kits (HUD Kit, Merchant GUI, Shop Index UI, Nametag Kit).
